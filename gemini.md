# Iron Pets

## Overview
Iron Pets is a modern, full-stack e-commerce platform for pet supplies, built with Next.js 14, Node.js 20, Express, and PostgreSQL. It features a product catalog, shopping cart, secure checkout with Stripe, user authentication, and personalized pet profiles.

## Technologies
- **Frontend**: Next.js 14, TypeScript, Tailwind CSS, Zustand, React Query
- **Backend**: Node.js 20, Express.js, PostgreSQL + Prisma, Redis, Stripe
- **Testing**: Jest, React Testing Library, Playwright

## Project Structure
- `src/iron-pets/frontend`: Next.js application
- `src/iron-pets/backend`: Express API server
- `docs/`: Project documentation
